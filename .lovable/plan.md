

## Plan: Página Web Escolar - I.E. 24009 "Túpac Amaru II"

Convertiremos tu código en una aplicación React completa con rutas y componentes organizados.

### 1. Estructura de Páginas
- **Página Principal (Institucional)**: Hero con llamada a la acción, accesos rápidos (calendario, biblioteca, rincón cívico, portal padres), sección de esencia educativa, metodología, formulario de admisiones y footer
- **Biblioteca Virtual**: Buscador de libros con filtros por categoría (Cuentos, Ciencia, Historia, Valores) y tarjetas visuales
- **Rincón Cívico Digital**: Reproductor de audio con himnos y marchas (Himno Nacional, Marcha de Banderas, Marcha Militar) con controles de reproducción completos
- **Portal para Padres**: Panel lateral con avisos/comunicados y sección de calificaciones con datos de ejemplo

### 2. Funcionalidades Clave
- **Bilingüismo completo**: Cambio entre Español y Quechua Chanka en toda la app
- **Navegación fluida** entre las 4 secciones usando React Router
- **Diseño responsive** para móvil y escritorio
- **Colores institucionales**: Azul (#0033CC), Rojo (#D63031), Ámbar como acento

### 3. Diseño Visual
- Estilo moderno con bordes redondeados grandes, sombras suaves
- Barra de navegación sticky con borde rojo inferior
- Tarjetas con efectos hover y transiciones
- Tipografía bold y limpia

### 4. Organización del Código
- Sistema de traducciones centralizado (es/qu)
- Componentes separados: `PaginaInstitucional`, `BibliotecaVirtual`, `RinconCivico`, `PortalPadres`
- Datos de libros y pistas de audio como constantes
